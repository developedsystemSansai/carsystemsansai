ทดสอบ / ส่งซ้ำข้อความ LINE

ทดสอบส่ง = ส่งข้อความจริงเฉพาะ แอดมิน (ไม่รบกวนผู้รับจริง) · ส่งจริงอีกครั้ง = สร้างข้อความ ใหม่จากข้อมูลล่าสุดตอนนี้ แล้วส่งให้ ผู้รับจริงตามบทบาท เหมือนที่ระบบส่งอัตโนมัติ (ส่งทาง LINE เท่านั้น ไม่ส่งอีเมลซ้ำ · ไม่ขึ้นกับสวิตช์เวลาอัตโนมัติ) — ทุกครั้งที่ส่งจะใช้โควต้า LINE ตามจำนวนผู้รับ และถูกบันทึกลงแท็บ "ประวัติการส่ง" พร้อม token ที่ใช้
ส่งข้อความจริงจากข้อมูลล่าสุดครบทุกชุดให้แอดมินเท่านั้น ใช้ดูหน้าตาข้อความบนมือถือ

ประวัติการส่ง LINE

บันทึกทุกครั้งที่ระบบยิง LINE API — ดูได้ว่าส่งผ่านบัญชีไหน (หลัก/สำรอง) และ token ตัวไหน (เก็บเฉพาะ 4 ตัวท้ายเพื่อแยกแยะ ไม่เก็บ token เต็ม) พร้อมผู้รับ จำนวนข้อความ โควต้าที่ใช้ และสถานะ · กด "ดูข้อความเต็ม" เพื่ออ่าน คัดลอก หรือ ส่งซ้ำข้อความเดิม
เปิดแท็บนี้เพื่อโหลดประวัติ

แก้ไขชุดข้อความ LINE
