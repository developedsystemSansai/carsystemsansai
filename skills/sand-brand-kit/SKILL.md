# SAND Brand Kit

ชุดสินทรัพย์และกติกาการวางภาพแบรนด์ SAND ให้ใช้ซ้ำได้ทุกหน้า ออกแบบ **มือถือก่อน** (ผู้ใช้หลักคือ พขร. ที่เปิดจากโทรศัพท์)

## ไฟล์ในสกิล
- `assets/icons/<key>.webp` (192px) และ `<key>-96.webp` (@1x) — ไอคอน 12 ตัว พื้นโปร่งใส
- `assets/poses/` — มาสคอต 4 ท่า (`ok` `laptop` `idea` `cheer`)
- `assets/anim/` — `wave` `loading` `alert` (WebP เคลื่อนไหว) + `-still.webp` ของแต่ละตัว
- `assets/logo/sand-logo.webp`, `assets/hero/hero-scene.webp`
- `assets/sand-brand.css`, `assets/sand-brand.js` — วิดเจ็ตแจ้งเตือน + ไอคอนประจำหน้า + สไตล์โหลด/ว่าง/สำเร็จ
- `references/asset-map.md` — ตารางว่าไฟล์ไหนใช้ที่ไหน และเหตุผล

## เมื่อต้องวางภาพแบรนด์ ให้ทำตามนี้
1. **จับคู่ความหมายก่อน** ดู `references/asset-map.md` แล้วเลือกไอคอนที่ตรงกับหน้า/ฟังก์ชัน ไม่ใช้ไอคอนซ้ำกับความหมายอื่น
2. **มาสคอตใช้เพื่อสื่ออารมณ์ ไม่ใช่ตกแต่ง**: `ok` ทักทาย/เริ่มต้น · `laptop` เข้าสู่ระบบ/ทำงาน · `idea` ไม่มีข้อมูล/คำแนะนำ · `cheer` สำเร็จ · `wave` hero หน้าแรก · `alert` แจ้งเตือน · `loading` รอโหลด
3. **มือถือก่อน**: ภาพมาสคอตใน hero กว้างไม่เกิน ~80px บนจอ <720px และต้องไม่ทับข้อความหรือปุ่ม; ปุ่มทุกอันสูง ≥44px
4. **ภาพเคลื่อนไหวต้องมีทางหนี**: ใช้ `<picture>` + `<source media="(prefers-reduced-motion: reduce)" srcset="...-still.webp">`
5. **ภาพตกแต่งใส่ `alt=""`**; ภาพที่สื่อความหมายเดียว (ไม่มีข้อความข้างๆ) ใส่ alt อธิบาย
6. ใส่ `width`/`height` และ `decoding="async"` เสมอ (กัน layout เลื่อน); ภาพใต้พับใส่ `loading="lazy"`

## วิดเจ็ตรถยังไม่ตรวจสภาพ (sand-brand.js)
- แสดงเฉพาะ **ก่อน 10:00 น. เวลาไทย** และเมื่อ `getStatusSummary.notCheckedToday` ไม่ว่าง; ถึง 10:00 ซ่อนเองโดยไม่ต้องรีโหลด
- เริ่มเป็นปุ่มกลม 56px มุมขวาล่าง แตะแล้วขยายรายการ (ไม่เด้งเต็มจอ) · ปุ่ม "ซ่อนวันนี้" จำผ่าน localStorage รายวัน
- หลบองค์ประกอบ `fixed/sticky` ชิดล่างของหน้าอัตโนมัติ และเพิ่ม `padding-bottom` ท้ายหน้าให้เลื่อนพ้นปุ่ม
- **ตั้งใจให้ใช้เฉพาะหน้าแรกและตารางเวร** (`CFG.reminderPages`) — ห้ามใส่ในหน้าฟอร์ม/แผนที่/แดชบอร์ดที่มีหน้ารหัสผ่านทับ เพราะบังช่องกรอก

## ติดตั้งในหน้าใหม่
```html
<link rel="stylesheet" href="sand-brand.css">
<script defer src="sand-brand.js"></script>
```
วางหลัง `secure-fetch.js` (วิดเจ็ตใช้ `GAS_URL` ที่ประกาศไว้ในหน้า) และคัดลอกโฟลเดอร์ `assets/sand/` ไปไว้ข้างไฟล์ HTML
