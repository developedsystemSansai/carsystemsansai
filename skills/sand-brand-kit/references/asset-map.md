# แผนที่การใช้งานสินทรัพย์ SAND

| ไฟล์ | ความหมาย | ใช้ที่ |
|---|---|---|
| icons/inspect | ตรวจสภาพรถ | การ์ดเมนู check · การ์ดสถานะ "รอตรวจสภาพ" · header check |
| icons/odometer | เลขไมล์ | การ์ดเมนู startmile · header startmile/editmile |
| icons/schedule | ตารางเวร | การ์ดเมนู worktable · header worktable |
| icons/repair | แจ้งซ่อม | การ์ดเมนู fixedcar · header fixedcar |
| icons/ems | งาน EMS | การ์ดเมนู EMScheck · header EMScheck/emsDashboard |
| icons/report | รายงานสถิติ | การ์ดเมนู dashboard · header dashboard |
| icons/route | แผนที่เส้นทาง | การ์ดเมนู routemap · การ์ดสถานะ "กำลังใช้งาน" · header routemap |
| icons/alert | แจ้งเตือน | การ์ดเมนู linecontrol · header linecontrol |
| icons/swap | แลกเวร | header swap · แท็บแลกเวร · ทรานซิชันเข้าสู่ swap |
| icons/vehicle | ยานพาหนะ | การ์ดสถานะ "พร้อมใช้งาน" |
| icons/settings | ตั้งค่าระบบ | การ์ดสถานะ "สถานะระบบ" |
| icons/fuel | บันทึกน้ำมัน | สำรอง (ยังไม่มีหน้าเฉพาะ) |
| poses/ok | ทักทาย | แถบ "เริ่มวันด้วยการตรวจสภาพรถ" (มือถือ) |
| poses/laptop | ทำงาน/เข้าสู่ระบบ | หน้าเข้าสู่ระบบ swap |
| poses/idea | ไม่มีข้อมูล | `.empty-state` ทุกหน้า |
| poses/cheer | สำเร็จ | `.modal-icon` (check, fixedcar, startmile) |
| anim/wave | ทักทาย | hero หน้าแรก |
| anim/loading | กำลังโหลด | `.loading-state` ทุกหน้า |
| anim/alert | แจ้งเตือน | วิดเจ็ตรถยังไม่ตรวจ |
